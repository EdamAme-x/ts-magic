# ts-magic

Magic of TypeScript

## Install

```bash
# npm
npm install ts-magic

# bun
bun add ts-magic

# pnpm
pnpm add ts-magic
```

## Usage

```ts
import {} from "ts-magic";
```

## Development

```bash
# Install dependencies
bun install

# Run tests
bun test

# Lint
bun run lint

# Format
bun run format

# Type check
bun run typecheck

# Build
bun run build
```

## Release

1. GitHub で新しい Release を作成（タグ: `v0.1.0` など）
2. GitHub Actions が自動で npm に publish
